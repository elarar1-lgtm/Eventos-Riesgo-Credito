# Eventos de Riesgo de Crédito

Presentación didáctica interactiva en HTML sobre diez eventos de riesgo de crédito.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `README.md` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)` y guarda.
6. Espera a que GitHub Pages publique el sitio. La dirección tendrá el formato `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

La presentación es un archivo independiente: la imagen de fondo está integrada en `index.html`, por lo que no requiere archivos de imagen adicionales.
